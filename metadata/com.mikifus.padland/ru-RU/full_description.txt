Padland — это приложение для управления, систематизацией и просмотра совместных документов через Etherpad и CryptPad.

Основные возможности:
- Добавление собственных серверов
- Группировка документов
- Совместимость с серверами Etherpad и CryptPad
- Импорт и экспорт базы данных
- Сортировка и пакетный выбор документов
- Импорт из буфера обмена при длительном нажатии кнопки создания нового документа
- Поддержка автономного режима

Padland позволяет хранить документы для совместной работы в одном месте, оставаясь при этом простым и лёгким приложением.
